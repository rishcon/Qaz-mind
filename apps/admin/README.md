# QazMind Admin

Панель управления платформой QazMind. Часть монорепозитория, см. корневой `README.md`.

- Адрес в разработке: http://localhost:5174
- Запуск: `npm run dev:admin` из корня или `npm run dev` вместе с QazMind Web.
- Проверки: `npm run typecheck --workspace @qazmind/admin`, `npm test --workspace @qazmind/admin`, `npm run build:admin`.

## Состояние данных

Вход администраторов и административный API ещё не подключены, поэтому панель не показывает данных:

- списки пусты, показатели — прочерки с пометкой «данные не загружены»;
- любое изменение отказывает с сообщением «Сервер администрирования не подключён». Сохранённым ничего не считается;
- статус подключения показан вверху каждого экрана (`ADMIN_API_CONNECTED` в `src/admin/services/adminService.ts`).

Когда появится API, `adminService` начнёт вызывать его вместо отказа. Страницы переписывать не придётся, нужна только асинхронная обработка ответов.

Модель доступа, роли и порядок выдачи прав: `docs/ADMIN_ACCESS.md`. Открытые технические вопросы: `docs/INTEGRATION.md`, раздел «Технический долг».
