# Импорт вопросов

Вопросы загружаются в админке: **Контент → Банк вопросов → Импорт**. Все вопросы попадают в банк черновиками. Опубликовать вопрос может только проверяющий, который не является его автором (`docs/ADMIN_ACCESS.md`).

Пример файла: [`docs/examples/questions.import.example.json`](examples/questions.import.example.json). Его же можно скачать кнопкой «Пример JSON» в мастере импорта. Вопросы из примера (`external_id` начинается с `EXAMPLE`) сервер не принимает.

## Форматы

| Формат | Когда |
|---|---|
| **JSON** — объект `{"format": "qazmind.questions.v1", "questions": [...]}` или просто список | основной, для скриптов и ИИ |
| **JSONL** — один вопрос на строку | для больших выгрузок |
| **CSV** — шаблон из мастера | для таблиц; поля те же, казахские колонки `...Kz` необязательны |

За один раз принимается **не больше 500 вопросов**. Файл принимается целиком или не принимается: одна ошибка останавливает весь импорт, и мастер показывает номер вопроса.

## Поля вопроса (JSON)

| Поле | Обязательно | Описание |
|---|---|---|
| `external_id` | да | Уникальный ID вопроса, например `hist-silk-0001`. Защищает от повторной загрузки того же файла |
| `subject` | да | ID предмета из списка ниже (или его код) |
| `difficulty` | да | `easy`, `medium`, `hard` |
| `points` | нет | 1–5, по умолчанию 1 |
| `text_ru` | да | Текст вопроса |
| `text_kz` | нет*, но нужен | Текст на казахском. Без него вопрос получит предупреждение и не подойдёт ученикам с казахским языком экзамена |
| `options` | да | От 2 до 5 вариантов: `[{"ru": "...", "kz": "..."}, ...]`. Буквы A, B, C… присваиваются по порядку |
| `correct` | да | Буква правильного варианта: `A`–`E` |
| `explanation_ru`, `explanation_kz` | нет, но нужны | Пояснение, которое видит ученик после ответа |
| `source` | да | Откуда вопрос: учебник, глава, страница. Проверяющий должен суметь найти это место |
| `keep_order` | нет | `true` — не перемешивать варианты (нужно для «Все перечисленное», «Верно А и Б» и подобных) |

## Что проверяется

Ошибки останавливают импорт:
- нет `external_id`, `source`, текста, сложности, предмета; предмет не найден;
- правильная буква вне диапазона вариантов;
- варианты ответа повторяются внутри одного вопроса;
- `external_id` повторяется в файле или уже есть в банке;
- `external_id` начинается с `EXAMPLE`.

Предупреждения показываются, но не блокируют:
- такой текст вопроса уже есть в банке или повторяется в файле;
- нет казахской версии;
- нет пояснения.

Перед записью мастер всегда делает пробную проверку на сервере (`POST /admin/questions/import?dry_run=true`) и ничего не сохраняет. Включённая галочка «Перемешать варианты» переставляет варианты и переносит букву правильного ответа вместе с вариантом, чтобы позиция ответа в банке не повторяла порядок, в котором его писал автор.

## ID предметов

`history_kz`, `math_lit`, `reading_lit` (обязательные); `math_prof`, `physics`, `biology`, `chemistry`, `geography`, `world_history`, `kaz_lang`, `kaz_lit`, `english` (профильные). Информатики в каталоге пока нет.

## Промпт для генерации вопросов с помощью ИИ

Вставьте в чат вместе с текстом параграфа и замените значения в скобках. Результат — черновик, который читает предметник. ИИ ошибается в фактах и ключах.

```
Ты составляешь вопросы для подготовки к ЕНТ (Казахстан) по предмету [ID предмета].
Используй ТОЛЬКО текст ниже. Не добавляй фактов, которых в нём нет.

Верни один JSON-объект без пояснений вокруг:
{"format": "qazmind.questions.v1", "questions": [ ... ]}

Каждый вопрос:
{
  "external_id": "[префикс]-0001",   // уникальный, нумерация подряд
  "subject": "[ID предмета]",
  "difficulty": "easy | medium | hard",
  "text_ru": "...", "text_kz": "...",
  "options": [{"ru": "...", "kz": "..."}, ... 4 варианта],
  "correct": "A | B | C | D",
  "explanation_ru": "...", "explanation_kz": "...",
  "source": "[учебник, класс, параграф, страницы]",
  "keep_order": false
}

Правила:
- 4 варианта, ровно один верный. Неверные варианты правдоподобны и близки по длине к верному.
- Не используй «Все вышеперечисленное», «Только …», «Ничего из перечисленного».
- Правильный ответ не должен быть самым длинным и должен быть на разных позициях A–D в разных вопросах.
- Вопрос проверяет понимание, а не только определение. Часть вопросов — на применение или сравнение.
- Русская и казахская версии означают одно и то же; пояснение — 1–2 предложения со ссылкой на текст.
- Сложность: easy — прямой факт, medium — связь двух фактов, hard — применение или анализ.
- Если текста не хватает для хорошего вопроса, верни меньше вопросов.

Количество вопросов: [N].

ТЕКСТ:
[вставьте параграф]
```

## Процесс

1. Подготовить файл (вручную, из таблицы или через ИИ) в этом формате.
2. В мастере выбрать файл: проверка на странице и на сервере. Исправить ошибки в файле и загрузить заново.
3. Импорт создаёт черновики. В банке вопросов их можно отметить галочками (или «Выбрать все N по текущим условиям») и одним действием отправить на рецензию либо удалить. Действие применяется только к черновикам, вопросы в других статусах пропускаются и считаются; удалить рецензируемый или опубликованный вопрос нельзя (опубликованный архивируется). Удаление черновиков безвозвратное и записывается в журнал аудита.
4. Предметник читает вопросы и утверждает или возвращает с замечаниями.
5. Другой человек публикует. Опубликованные вопросы видны практике и пробному экзамену.
