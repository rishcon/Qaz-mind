## Этап 2 — аккаунты и сессии

- [x] Регистрация, подтверждение email по одноразовому токену (хеш в БД, срок 24 ч)
- [x] Повторная отправка с кулдауном 60 с; одинаковый ответ для существующих и новых адресов
- [x] Вход: общий текст ошибки, проверка пароля до проверки подтверждения, Argon2id
- [x] Блокировка после 5 неудачных попыток на 15 минут (по аккаунту)
- [x] Сессия в HttpOnly-cookie, хранится хеш токена; ротация при входе; отзыв при выходе
- [x] Восстановление пароля: одноразовый токен 60 мин, отзыв всех сессий после сброса
- [x] CSRF double-submit (`qm_csrf` + `X-CSRF-Token`) для всех изменяющих запросов
- [x] `/auth/me` как источник правды после перезагрузки
- [x] Фронтенд: `apiClient`, `AuthProvider`, защищённые маршруты, без `autostart`
- [ ] **Письма не доставляются.** Адаптер `dev_log` пишет письма в лог сервера. Staging и production не стартуют с ним (`validate_for_environment`). Нужен реальный SMTP/транзакционный адаптер и домен почты (открытое решение ТЗ п. 22.2).
- [ ] MFA для сотрудников школ (нужно к пилоту, этап 6+)
- [ ] Лимит попыток по IP (сейчас только по аккаунту; нужен Redis или прокси-лимит)
- [ ] Очистка истёкших сессий и токенов (фоновая задача не добавлена)
- [~] CORS: origins задаются переменной; не проверено на реальном домене

- [x] Тесты изоляции: два пользователя видят только свой профиль
- [x] Тест: период «ЕНТ 2027» только для 2027 года

## Этап 4 — учебный контент и уроки

- [x] Таблицы `subjects` (12 предметов, засеяны), `curriculum_topics`, `lessons`, `lesson_versions` (JSONB-шаги, CHECK статусов, один опубликованный вариант на урок), `lesson_progress`
- [x] Формат файла контента с проверкой (лишние поля и дубли slug отклоняются до записи)
- [x] Жизненный цикл: draft → in_review → approved → published → archived; автор не утверждает и не публикует свой материал; новая публикация архивирует прежнюю в той же транзакции
- [x] CLI: `python -m app.content.cli import|status|transition`
- [x] API: `/subjects` (счётчик только опубликованных уроков), `/subjects/{id}/curriculum`, `/lessons/{slug}` (только опубликованная версия), `PUT /me/lessons/{slug}/progress`, `GET /me/progress`
- [x] Прогресс: позиция сохраняется, завершение не отменяется, шаги проверяются по уроку
- [x] Фронтенд: экран предметов и экран урока читают сервер; вопрос-чекпоинт прототипа убран (это практика, этап 5); пустые состояния вместо выдуманных цифр
- [x] Прототипные цифры «1420 вопросов», «48 тем» удалены из данных
- [x] Сквозной сценарий проверен по HTTP на контейнерах: счётчики, программа, урок, сохранение позиции, завершение
- [~] **Контент не опубликован.** Четыре урока прототипа экспортированы в `backend/content/drafts/` как ИИ-черновики без экспертной проверки. Ученики их не видят. Публикация требует ревьюера и сверки с учебником (открытое решение: кто проверяет, см. ТЗ п. 22.8)
